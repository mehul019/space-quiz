# Space Quiz

A 10-question space exploration quiz in a single `index.html` with no dependencies. It has a progress bar, score and best-score tracking, animated feedback, shuffled questions, a results screen, and light/dark themes.

## Run locally

Open `index.html` in any modern browser. No server or build step is needed.

## Deployment

Pushes to `main` deploy automatically to GitHub Pages via `.github/workflows/deploy.yml`.
