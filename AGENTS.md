# Space Quiz – agent instructions

- The whole app is a single `index.html` (HTML, CSS, JS inline). No build step, server, or runtime dependencies.
- Keep it accessible: semantic elements, visible focus states, full keyboard use, ARIA for progress, respect `prefers-reduced-motion`.
- Preserve both light and dark themes (`prefers-color-scheme`) via the CSS variables in `:root`.
- Plain sans-serif body at 14–16px; keep the narrow centered column.
- Comment code sparingly, only where intent is unclear.
- Verify every change in a browser: play through questions, check score, progress, correct/wrong feedback, and the results screen.
